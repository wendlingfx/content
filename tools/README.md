# Video generator

`python3 tools/make_video.py auto media/` builds today's video from the live numbers on wendlingfx.com
(Mon: weekly scoreboard, Wed: latest trades, Fri: account growth). `ctrader` builds the copy trading explainer.
Rules: English, percentages only, losses shown, no promises, disclaimer on the end card.

Fonts: Unbounded and Inter, SIL Open Font License. Music: Pixabay Content License (tracks trimmed to start where the music is playing).
